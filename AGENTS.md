# AGENTS.md

Rules for anyone changing this repository. What it is: [README.md](README.md).

- The scheduled run's procedure is [REVIEW.md](REVIEW.md). It is read by an agent with no other context: every rule the run
  needs is in that file, and a rule in that file is written so it can be followed without asking anyone.
- The run only writes issues of this repository. A change that lets it push, open pull requests or write anywhere else
  needs the owner's explicit approval.
- No code until a real need shows up: the state and the proposals live in issues, so there is nothing to build or test.
- The main branch is `master`.
